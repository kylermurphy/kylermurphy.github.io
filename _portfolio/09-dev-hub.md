Research code rarely gets tests, CI, or up-to-date packaging once it works. `dev-hub` is a small private repo holding a task board, a playbook, and a record of work. An AI agent picks up a named task, works it on a branch, and hands back a pull request for review. A generic MIT-licensed [template](https://github.com/kylermurphy/dev-hub-template) is public; the design is described in two posts ([part 1](/posts/2026/09/post-10/), [part 2](/posts/2026/09/post-11/)).
